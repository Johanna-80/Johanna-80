# Johanna Vásquez | QA Engineer Jr.

Trabajo con pruebas funcionales, de regresión y de API. Diseño casos a partir de requisitos, compruebo respuestas y documento resultados que puedan repetirse y revisarse.

Me interesa que el software haga lo que necesita la persona que lo usa. Mi experiencia previa coordinando proyectos, revisando documentación y elaborando informes me ayuda a dar seguimiento a tareas, identificar inconsistencias y explicar los hallazgos con claridad.

## Qué hago

- **Testing manual:** escenarios positivos/negativos, formularios, navegación, regresión y reportes de errores.
- **API Testing:** solicitudes HTTP, estados de respuesta, JSON, validación de datos y casos límite.
- **Automatización:** Python, Requests y pytest; primeros flujos de interfaz con Selenium.
- **Seguimiento:** Jira, hojas de cálculo y comunicación de resultados.
